# 주간 시황브리핑 생성

SK증권 영업점 담당자가 수요일 아침 회의에서 구두 발표하는 주간 시황브리핑을 만든다.

**청중은 주식영업 15년 이상 경력자다(2026-09-29 확인).** 용어 설명·기초 해설을 넣지 않는다.
FOMC·PCE·프로그램매매·괴리율 같은 용어는 그대로 쓴다. 같은 시간에 더 많은 정보가 들어가도록
문장당 밀도를 높이고, 고객 응대에 바로 쓰이는 것을 우선한다:
밸류에이션(선행 PER·컨센서스), 수급 주체별 금액, 업종·종목 등락, 실적 가이던스와 비교 기준선,
환율·금리가 실적 추정에 미치는 경로, 예정 이벤트의 시각까지.

## 집계 기준 (가장 중요)

> **지난주 화요일 15:00 ~ 이번주 화요일 15:00**

작성은 화요일 15:00 이후, 발표는 수요일 아침. 백데이터 파일명의 날짜는 **수집 기간**(화→화)이지
생성일이 아니다. **오늘 날짜로 끝나는 파일**을 쓴다. (예: 9/1 작성 → `0825_0901_...`)

## 산출물

- 파일명: `MMDD_MMDD_시황브리핑_발표용.docx` (예: `0825_0901_시황브리핑_발표용.docx`)
- 분량은 발표 시간에 맞춘다. **한국어 격식체 낭독은 350~450자/분**(실측):

| 목표 | 본문 글자수 | 불릿 수 | 분량 |
|---|---|---|---|
| 1분 | 450~500자 | 5~6개 (섹션당 1개) | A4 반쪽 |
| **2분 (기본값)** | **850~950자** | **11개 내외 (섹션당 2~3개)** | **A4 1쪽** |
| 3분 | 약 1,300자 | 15~16개 | A4 1.5쪽 |

- 섹션 5개 구조는 어떤 분량에서도 유지한다.
- 작성 후 **`본문 글자수 ÷ 400`으로 낭독 시간을 반드시 확인**한다.
- 요청이 없으면 2분을 기본값으로 한다.

> ⚠️ 이 스킬의 예전 판에는 "5섹션 × 3~4불릿 = 1~2분"으로 적혀 있었으나
> 실측 결과 그 분량(20불릿·2,300자)은 **약 6분**이다. 위 표가 교정된 값이다.

## 절대 원칙

1. **사실만 기재. 의견·전망·투자판단 금지 — 출처를 밝혀도 금지.**
   - "…로 판단했습니다 / 전망했습니다" 형태는 **출처를 명시해도 넣지 않는다.**
     (예: "모건스탠리는 …로 상향했습니다"도 제외)
   - 투자의견·목표주가·추천 업종·전략 제안(바벨 전략, 비중 확대 등)도 제외.
   - "~로 보입니다", "~가 유효합니다" 같은 무출처 판단 표현을 쓰지 않는다.
   - **넣는 것**: 지수·금리·환율·유가 레벨, 실적 수치, 수급 숫자, 정책·규제 변경 사실,
     컨센서스 수치, 예정 일정. 판단이 필요한 대목은 사실만 두고 해석은 발표자에게 맡긴다.
2. **모든 수치는 백데이터에서 직접 확인한 값만 사용.** 기억이나 추정으로 채우지 않는다.
   - 종가가 없고 익일 장중 시세만 있으면 역산해서 검증한다.
     (예: 익일 장중 `6,337.94(-257.51p)` → 전일 종가 `6,595.45`)
3. **존댓말 격식체**(~습니다)로 작성한다. 이모지 금지.
4. **주식영업 담당자 기준**으로 고객 응대에 바로 쓸 수 있는 정보를 우선한다.
5. 채널 원문을 그대로 옮기지 않는다. **문장은 새로 작성한다.**
   모든 산출물은 사내 참고용이며 대외 배포·인용 금지다.

## 구두 발표용 문장 규칙

- **한 문장에 숫자 3개 이상 금지.** 길면 나눈다. (날짜·서수는 세지 않는다)
- **괄호식으로 붙여 쓰지 않는다.** `6,345.53(+0.73%)` → "6,345.53으로 0.73% 올랐습니다".
  수치는 문장 안에 자연스럽게 분산시킨다.
- 불릿 첫 문장은 짧게 상황을 제시하고, 숫자는 뒤에 붙인다.
- 접속 표현("그런데", "다만", "반면")으로 흐름을 잇는다.

## 작업 순서

### 1) 백데이터 통독

```bash
grep -n "^# 20" <파일>.txt          # 일자 블록 확인
grep -n "마켓 클로징\|Global Market Snapshot" <파일>.txt   # 종가·해외지표 앵커
```

docx면 `pandoc -t markdown <파일>.docx -o news.md`로 변환한다.
파일이 크므로(30만자 이상) **300~500줄 단위로 순차 통독**한다. 요약본만 보고 쓰지 않는다.

**주의**: 아카이브는 채널에 남아 있던 옛 글까지 매일 다시 수집하므로 **같은 메시지가 여러 날짜
블록에 중복**되고, 집계 기간 밖의 글도 섞여 있다. 날짜를 반드시 확인하고 쓴다.

우선 추출할 것:
- 일자별 코스피/코스닥 **종가**와 등락률 (마켓 클로징 메시지)
- 미국 3대 지수·필라델피아 반도체지수 종가 (Global Market Snapshot)
- 국채금리(2·10·30년), 달러인덱스, 달러/원, 달러/엔, WTI·브렌트
- 주요 기업 실적 수치(매출·EPS·가이던스·FCF)
- FOMC·금통위·경제지표 결과값과 컨센서스
- 수급(외국인 순매수·순매도 누적, 자사주, 신용융자잔고)
- 정책·규제 변경, 다음 주 예정 일정

### 2) 지난주 발표자료 대조

직전 회차 파일이 함께 업로드되면 서식·톤·섹션 구성을 그대로 따른다.

### 3) 섹션 구성 (5개 고정, 주차별로 제목 문구만 변경)

```
[MM/DD~MM/DD 시황 브리핑] {한 주를 요약하는 제목}
1. 국내 증시: {한 주 성격}
2. 이번 주 최대 이슈: {등락 원인과 트리거}
3. 통화정책·금리·환율
4. 수급 및 정책 이슈
5. 지표·섹터 및 향후 일정
```

그 주에 압도적인 단일 이슈가 있으면 2번 섹션 제목을 그것으로 바꾼다.

### 4) 강조 표기

`**...**`로 감싸면 볼드 + 노란 음영으로 렌더링된다.

- **섹션당 1~2개.** 총개수는 분량에 비례시킨다 — **2분 기준 5개 내외**.
- 분량이 줄었는데 개수를 유지하면 거의 모든 불릿이 노랗게 되어 강조 효과가 사라진다.
- 대상은 **기록·전환점이 되는 숫자**로 한정한다.
  (사상 최초/역대 1위, 서프라이즈 실적 핵심 지표, 수급 반전 수치)
- 문장 전체가 아니라 핵심 구절만 감싼다.

### 5) 문서 생성

`content.json`을 작성한 뒤:

```bash
node <skill_dir>/scripts/build_briefing.js content.json <출력>.docx
```

`content.json` 형식:

```json
{
  "title": "[8/25~9/1 시황 브리핑] 금리는 올랐고, AI 수요는 확인됐습니다",
  "sections": [
    {
      "head": "1. 국내 증시: 지수는 올랐지만 내부는 엇갈린 한 주",
      "bullets": [
        "코스피는 한 주 동안 1.15% 올라 6,820.02로 마감했습니다. 코스닥도 0.86% 오른 834.29입니다."
      ]
    }
  ]
}
```

빌드에는 Node.js와 `docx` 패키지가 필요하다. 없으면 스킬 폴더에서 `npm install docx`.

### 6) 검증 (생략 금지)

① 음영이 `**...**` 구간에만 걸렸는지 ② 줄바꿈 깨짐 ③ 분량·낭독 시간을 확인한다.

LibreOffice가 있으면 이미지로 렌더해 눈으로 본다:

```bash
soffice --headless --convert-to pdf <출력>.docx && pdftoppm -jpeg -r 90 <출력>.pdf page
```

**LibreOffice/pdftoppm이 없거나 변환에 실패하는 환경이 있다.** 그때는 docx의 XML을 직접 파싱한다:

```bash
python3 -c "
import zipfile
from xml.etree import ElementTree as ET
W='{http://schemas.openxmlformats.org/wordprocessingml/2006/main}'
root=ET.fromstring(zipfile.ZipFile('<출력>.docx').read('word/document.xml').decode('utf-8'))
tot=0
for p in root.iter(W+'p'):
    t=''.join(x.text or '' for x in p.iter(W+'t')); tot+=len(t)
    k='불릿' if p.find('.//'+W+'numPr') is not None else '머리'
    for r in p.iter(W+'r'):
        if r.find('.//'+W+'shd') is not None:
            print('  음영:', ''.join(x.text or '' for x in r.iter(W+'t')))
    print(f'[{k}] {len(t):3d}자 {t[:40]}')
print('본문 합계', tot, '자 → 낭독 약', round(tot/400,1), '분')
"
```

### 7) 답변

파일을 전달하고 **발표 시 강조할 포인트 3가지**를 불릿으로 덧붙인다.

## 화면 투사용 PDF (요청 시)

발표 중 화면에 띄우고 설명할 용도. docx(원고)와 짝으로 만든다.

> **★ PDF 본문은 개조식 — 존댓말을 쓰지 않는다 (2026-09-29 확인).**
> docx(원고)는 낭독용이라 존댓말, **PDF는 보여주는 자료라 개조식**이다. 둘을 섞지 않는다.
> 각 섹션은 `한 줄 결론(.lead, 숫자 포함)` + `보조 사실 3~4개(.li)` 구조로 쓴다.
> 화살표(→)·가운뎃점(·)·대시(—)로 관계를 압축하고, 숫자는 굵게, 배경 설명은 흐리게.
>
> **★ PDF 블록 순서 = docx 섹션 순서 ①~⑤ (2026-09-29 개편, 절대 규칙)**
> 발표자가 1쪽↔2쪽을 오가지 않도록 위에서 아래로만 읽히게 배치한다.
> 각 블록에 docx와 **같은 번호·같은 제목**을 단다.
> 순서를 깨는 요약 카드("핵심 3가지" 등)를 따로 만들지 않는다 — 되돌아보게 만드는 원인이었다.

**같은 내용을 두 문서에 쓰는 법 (2026-09-29 실제 사례):**

| | 문장 |
|---|---|
| docx (낭독용, 존댓말) | 코스피는 연휴 전 7,080.92까지 올랐습니다. 그런데 복귀 첫 거래일인 월요일에 2.70% 급락해 6,889.74로 마감했습니다. |
| PDF `.lead` (개조식) | 연휴 전 고점 **7,080.92** → 복귀 첫날 **−2.70%** |
| PDF `.li` (보조 사실) | 코스닥은 <span class="hl">+1.46%</span> · 846.58 — 지수와 반대 방향 |

- `.lead`는 **주어를 생략하고 숫자 두 개로 결론만** 남긴다. 조사·서술어를 화살표로 대체한다.
- `.li`는 한 줄에 사실 하나. `·`로 수치를 잇고, 해석이 필요한 대목은 `—` 뒤에 짧게 붙인다.
- docx 문장을 그대로 잘라 붙이지 않는다. 낭독용 연결어("그런데", "다만")는 PDF에서 전부 뺀다.

- 파일명: `MMDD_MMDD_시황브리핑_핵심요약.pdf`, **A4 가로 2쪽**
- **1쪽: KPI 4개 + 섹션 ① + 섹션 ②**
- **2쪽: 섹션 ③ + 섹션 ④ + 섹션 ⑤**
- 각 섹션 카드는 `[번호 뱃지 + docx와 동일한 제목 + 기준 시점]` 머리에
  `차트 | 요지 불릿` 2열 본문. 요지는 docx 불릿을 압축한 것이어야 한다.
- **뼈대와 CSS는 `templates/highlight.html`에 있다. 매번 새로 쓰지 말고 그 파일을 복사해 쓴다.**
  (`briefings/`는 .gitignore 대상이라 컨테이너가 바뀌면 지난 주 결과물이 사라진다)
- HTML로 작성하고 차트는 인라인 SVG로 직접 그린다.
- 한글 폰트가 없는 환경이면 `npm pack @fontsource/noto-sans-kr`으로 받아
  woff2를 base64로 HTML에 내장한다.
- 변환 후 **페이지를 이미지로 렌더해 직접 보고** 잘림·겹침·빈 공간을 확인한다.

성장률·상승률처럼 비율이 아닌 값을 게이지(진행률) 막대로 그리지 않는다. 오해를 부른다.

## 표기 규칙

- "전년비" → **"전년 대비"**, "전기비" → "전분기 대비"
- 지수·등락률은 소수점 둘째 자리까지
- 금액 단위 통일: 조/억 원, 억/조 달러
- 이모지 사용하지 않는다 (발표용 문서)

# 주간 시황브리핑 생성

## 산출물
- 파일명: `MMDD_MMDD_시황브리핑_발표용.docx` (예: `0728_0804_시황브리핑_발표용.docx`)
- 분량: **5개 섹션 × 2~3 불릿(11개 내외), 본문 850~950자, A4 1쪽 — 구두 발표 2분 내외**
  (낭독 350~450자/분 실측 기준. 자세한 표는 CLAUDE.md 5-5 참조.
  기존 "3~4불릿 = 1~2분" 표기는 실측 약 6분으로 틀린 값이었다.)
- 함께 만드는 화면 투사용 PDF: CLAUDE.md 5-6 참조
- 저장 위치: 레포의 `briefings/` (구 claude.ai 경로 `/mnt/user-data/outputs/`)

## 절대 원칙
1. **사실만 기재. 의견·전망·투자판단 금지 — 출처를 밝혀도 금지.**
   - "…로 판단했습니다 / 전망했습니다" 형태는 **출처를 명시해도 넣지 않는다.**
     (예: "모건스탠리는 …로 상향했습니다"도 제외) — 2026-08 사용자가 강화한 규칙.
   - 투자의견·목표주가·추천 업종·전략 제안도 제외.
   - "~로 보입니다", "~가 유효합니다" 같은 무출처 판단 표현을 쓰지 않는다.
   - 넣는 것: 지수·금리·환율·유가 레벨, 실적 수치, 수급 숫자, 정책·규제 변경 사실,
     컨센서스 수치, 예정 일정. 판단이 필요한 대목은 사실만 두고 해석은 발표자에게 맡긴다.
2. **모든 수치는 백데이터에서 직접 확인한 값만 사용.** 기억이나 추정으로 채우지 않는다.
   - 백데이터에 종가가 없고 익일 장중 시세만 있으면 역산해서 검증한다.
     (예: 익일 장중 `6,337.94(-257.51p)` → 전일 종가 `6,595.45`)
3. **존댓말 격식체**(~습니다)로 작성한다.
4. **주식영업 담당자 기준**으로 고객 응대에 바로 쓸 수 있는 정보를 우선한다.
   지수 레벨·등락률, 실적 수치, 금리·환율·유가 레벨, 수급 숫자, 정책 변경, 예정 일정.

## 작업 순서

### 1) 백데이터 읽기
```bash
pandoc -t markdown /mnt/user-data/uploads/<파일>.docx -o news.md
grep -n "^\\\\\[20" news.md   # 메시지 타임스탬프 목록으로 구조 파악
```
파일이 크므로(보통 30만자 이상) 300~500줄 단위로 순차 통독한다. 요약본만 보고 쓰지 않는다.

우선 추출할 것:
- 일자별 코스피/코스닥 **종가**와 등락률 (마켓 클로징 메시지)
- 미국 3대 지수·필라델피아 반도체지수 종가 (Global Market Snapshot)
- 국채금리(2·10·30년), 달러인덱스, 달러/원, 달러/엔, WTI·브렌트
- 주요 기업 실적 수치(매출·EPS·가이던스·FCF)
- FOMC·경제지표 결과값과 컨센서스
- 수급(외국인 순매도 누적, 신용융자잔고, 레버리지 ETF)
- 정책·규제 변경, 다음 주 예정 일정

### 2) 지난주 발표자료 대조
직전 회차 파일이 함께 업로드되면 서식·톤·섹션 구성을 그대로 따른다.

### 3) 섹션 구성 (기본형)
```
[MM/DD~MM/DD 시황 브리핑] {한 주를 요약하는 제목}
1. 국내 증시: {한 주 성격}
2. {주간 최대 이슈 - 등락 원인과 트리거}
3. 통화정책·금리·환율
4. 수급 및 정책 이슈
5. 지표·섹터 및 향후 일정
```
그 주에 압도적인 단일 이슈가 있으면 2번 섹션 제목을 그것으로 바꾼다.

### 4) 강조 표기
섹션당 1~2개, 문서 전체 5~7개만 `**...**`로 감싼다. 볼드 + 노란 음영으로 렌더링된다.
대상은 **기록·전환점이 되는 숫자**로 한정한다. (사상 최초/역대 1위, 서프라이즈 실적 핵심 지표, 수급 반전 수치)
문장 전체가 아니라 핵심 구절만 감싼다.

### 5) 문서 생성
`content.json`을 작성한 뒤:
```bash
cd /home/claude && node <skill_dir>/scripts/build_briefing.js content.json /mnt/user-data/outputs/MMDD_MMDD_시황브리핑_발표용.docx
```

`content.json` 형식:
```json
{
  "title": "[7/28~8/4 시황 브리핑] 사상 최대 폭락, 그리고 사상 최대 반등",
  "sections": [
    {
      "head": "1. 국내 증시: 역대 기록을 갈아치운 한 주",
      "bullets": [
        "코스피는 7/28 -10.8%, 7/29 -5.98%로 이틀 연속 서킷브레이커가 발동됐습니다. **이틀 연속 서킷 발동은 코스피 사상 처음입니다.**"
      ]
    }
  ]
}
```

### 6) 검증 (생략 금지)
```bash
python3 /mnt/skills/public/docx/scripts/office/soffice.py --headless --convert-to pdf <출력>.docx
pdftoppm -jpeg -r 90 <출력>.pdf page
```
생성된 이미지를 직접 열어 ① 음영 위치 ② 줄바꿈 깨짐 ③ 분량(2쪽 이내)을 확인한다.

### 7) 답변
`present_files`로 파일을 전달하고, 발표 시 강조할 포인트 3가지를 불릿으로 덧붙인다.

## 표기 규칙
- "전년비" → **"전년 대비"**, "전기비" → "전분기 대비"
- 지수는 소수점 둘째 자리, 등락률은 둘째 자리 (`6,358.95(+1.62%)`)
- 금액 단위 통일: 조/억 원, 억/조 달러
- 종목명 뒤 등락률은 괄호 (`삼성전자(+22.95%)`)
- 이모지 사용하지 않는다 (발표용 문서)

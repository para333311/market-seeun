# market-seeun — 세은 시황자동화

주간 증시뉴스 백데이터(카카오톡/텔레그램 대화 로그)를 받아 아침 회의 발표용
1~2분 분량 시황브리핑 문서(docx)를 자동으로 생성하기 위한 저장소입니다.

## 현재 상태

- 브리핑 생성 프로세스와 폴더 구조만 구축된 단계입니다.
- 백데이터를 이 시스템에 자동으로 전달하는 방법(이메일 수신, 수동 업로드 등)은
  아직 결정되지 않았으며, 추후 별도로 확정할 예정입니다.
- 현재는 백데이터를 `backdata/` 폴더에 직접 올리고, Claude Code에게 브리핑
  생성을 요청하는 수동 워크플로로 사용합니다.

## 폴더 구조

```
market-seeun/
├── backdata/     # 주간 증시뉴스 백데이터 원본 (카톡/텔레그램 로그, docx·txt)
└── briefings/    # 생성된 시황브리핑 결과물 (docx)
```

### 파일명 규칙

- 백데이터: `{시작일YYYYMMDD}_{종료일YYYYMMDD}_증시뉴스.docx` (또는 `.txt`)
  - 예: `20260817_20260821_증시뉴스.docx`
- 생성된 브리핑: `{시작일YYYYMMDD}_{종료일YYYYMMDD}_시황브리핑.docx`
  - 예: `20260817_20260821_시황브리핑.docx`

## 사용 방법

1. 해당 주의 증시뉴스 백데이터 파일을 `backdata/` 폴더에 추가합니다.
2. Claude Code 세션에서 브리핑 생성을 요청합니다. (예: "이번 주 백데이터로
   시황브리핑 만들어줘") → `weekly-market-briefing` 스킬이 자동으로 적용됩니다.
3. 생성된 결과물을 `briefings/` 폴더에 저장하고 커밋합니다.
